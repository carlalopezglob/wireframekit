# _eliminar

Ficheros retirados del catálogo (módulos o specs antiguos que un módulo nuevo ha
sustituido), archivados aquí en vez de borrados por si hace falta consultar el
contenido anterior. No forman parte del kit activo: ningún `registry/[CAT].md`
ni `catalogo-visual.html` los referencia.

Se pueden borrar de verdad cuando nadie necesite ya el histórico (por ejemplo, al
hacer una limpieza de versión mayor del kit).
