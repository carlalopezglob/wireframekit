# CAT-FRM — Formularios

Formularios completos de página: contacto, autenticación, búsqueda y flujos de varios pasos.

| Código | Nombre | Cuándo usar |
| --- | --- | --- |
| CAT-FRM-001 | Formulario de contacto | Página o sección de contacto en landing pages, para enviar una consulta directa. |
| CAT-FRM-002 | Login / Registro | Pantalla de autenticación cuando el sitio requiere cuenta de usuario; combina login y registro en pestañas. |
| CAT-FRM-003 | Buscador con filtros | Búsqueda de contenidos, catálogos o bases de conocimiento, con filtrado por categoría u otros criterios. |
| CAT-FRM-004 | Formulario multi-paso | Formularios largos (checkout, onboarding, solicitudes complejas) divididos en pasos con progreso visible. |
