# CAT-COM — Componentes atómicos

Elementos de interfaz de un solo propósito, reutilizados dentro de los módulos de otras categorías (botones, campos, badges, avatares, estados de carga, tooltips, chips, toasts). No son secciones de página por sí mismos.

| Código | Nombre | Cuándo usar |
| --- | --- | --- |
| CAT-COM-001 | Botón | Acción principal, secundaria, terciaria, de enlace o destructiva. Base de cualquier CTA del kit. |
| CAT-COM-002 | Input de texto | Campo de entrada de texto, email, teléfono o textarea. |
| CAT-COM-003 | Select | Selección entre opciones predefinidas con `<select>` nativo. |
| CAT-COM-004 | Badge / Tag | Etiqueta inline no interactiva para categorizar o indicar estado. |
| CAT-COM-005 | Checkbox y Radio | Selección múltiple independiente (checkbox) o única dentro de un grupo (radio). |
| CAT-COM-006 | Toggle | Activar/desactivar una opción de efecto inmediato, sin confirmación. |
| CAT-COM-007 | Avatar | Representar a una persona: foto, iniciales o icono anónimo; con estado de presencia o agrupado. |
| CAT-COM-008 | Loader | Indicar carga: spinner, puntos, barra de progreso o skeleton. |
| CAT-COM-009 | Tooltip | Información adicional breve al hover/focus, sin ocupar espacio permanente. |
| CAT-COM-010 | Chip / Filtro | Etiqueta clicable para filtrar, seleccionar categoría o resumir filtros activos. |
| CAT-COM-011 | Toast / Notificación | Informar sobre el resultado de una acción: banner inline o toast flotante. |
| CAT-COM-012 | Widget flotante | Punto de contacto persistente (chat, ayuda, mensajería) visible en toda la navegación del sitio, fijo en una esquina del viewport. |

> El número 013 queda retirado: "Bloque social (iconos)" se descartó del kit por ser demasiado
> simple para justificar un módulo propio — se compone a mano con CAT-COM-001 (Botón) cuando un
> proyecto lo necesite.
>
> CAT-CRD-001 "Card básica" no vive aquí: aunque es un componente de un solo ítem, se agrupa en CAT-CRD (cards de contenido) porque su propósito es mostrar un ítem editorial, no una primitiva de interfaz.
