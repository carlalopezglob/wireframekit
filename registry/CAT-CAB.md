# CAT-CAB — Cabecera

Heroes y headers de página. Todo el mundo empieza una página con uno de estos.

| Código | Nombre | Cuándo usar |
| --- | --- | --- |
| CAT-CAB-001 | Hero principal | Hero de apertura con impacto visual o de mensaje. Incluye 3 variantes intercambiables: imagen de fondo, split texto+imagen, y centrado (landing de producto). |
| CAT-CAB-003 | Header ligero sin imagen | Páginas funcionales o utilitarias (buscadores, formularios, procesos) donde el hero visual no aporta. |

> El número 002 queda retirado: las variantes "split" y "centrado" que antes eran módulos independientes ahora viven dentro de CAT-CAB-001 (ver su Historial).
