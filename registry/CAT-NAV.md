# CAT-NAV — Navegación

Elementos de navegación estructural, siempre visibles en la página (a diferencia de las capas flotantes de CAT-MDL).

| Código | Nombre | Cuándo usar |
| --- | --- | --- |
| CAT-NAV-001 | Nav bar | Barra de navegación principal fija, con acceso global a las secciones y un CTA de conversión. |
| CAT-NAV-002 | Footer completo | Pie de página para sitios con varias secciones: navegación secundaria, contacto y legales. |
| CAT-NAV-003 | Breadcrumbs | Páginas interiores de 2+ niveles de profundidad, para orientación y ruta de regreso. |
| CAT-NAV-004 | Paginación | Listados de resultados, blogs o catálogos con más de una página. |
| CAT-NAV-005 | Stepper | Progreso en un proceso de varios pasos, mostrado de forma siempre visible. |
| CAT-NAV-006 | Lista de enlaces | Bloque titulado de enlaces: navegación por anclas, sidebar de páginas hermanas, enlaces relacionados o documentos descargables. |
