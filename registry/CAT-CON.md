# CAT-CON — Contenido

Módulos de sección de contenido: bloques de texto, texto+imagen, componentes de expansión, navegación de contenido y captación.

| Código | Nombre | Cuándo usar |
| --- | --- | --- |
| CAT-CON-001 | Bloque texto + imagen | Sección editorial que combina texto argumental con apoyo visual. Usar cuando hay un punto de valor que se refuerza con una imagen o ilustración. |
| CAT-CON-002 | Bloque solo texto | Secciones de contenido editorial puro sin imágenes: introducción de sección, propuesta de valor, contexto antes de un CTA. |
| CAT-CON-003 | Cita destacada | Resaltar un testimonio, una cita de cliente, un dato memorable o una declaración de posicionamiento. |
| CAT-CON-005 | Stats | Destacar métricas clave, KPIs o datos de impacto. Efectivo como separador visual entre secciones. |
| CAT-CON-006 | Acordeón FAQ | Preguntas frecuentes, políticas, especificaciones técnicas o cualquier contenido que se beneficie de revelarse progresivamente. |
| CAT-CON-007 | Tabs de contenido | Organizar contenido relacionado en secciones discretas sin necesidad de comparación directa. |
| CAT-CON-008 | Timeline / Proceso | Proceso secuencial, roadmap, etapas de un servicio o línea de tiempo, donde el orden es el mensaje central. |
| CAT-CON-009 | Bloque de características | Conjunto de características, funcionalidades o beneficios en grid escaneable, con marcador (icono/imagen/ninguno) y contenido flexible por columna (texto, lista o stats). |
| CAT-CON-010 | Banner CTA | Franja de llamada a la acción, normalmente de cierre de página o sección. |
| CAT-CON-011 | Muro de logos | Logos de clientes, partners o medios para transmitir confianza o prueba social. |
| CAT-CON-012 | Sección de equipo | Presentar a las personas de un equipo con foto, nombre, cargo y opcionalmente bio y enlaces sociales. |
| CAT-CON-013 | Galería de imágenes | Colección de imágenes o vídeos con lightbox de ampliación. |
| CAT-CON-014 | Newsletter / Suscripción | Captar suscripciones a una newsletter, como bloque de página o cierre de sección. |
| CAT-CON-015 | Visor de documento interactivo | Mostrar un documento paginado (PDF, catálogo, informe, presentación) con sus propios controles de lectura (zoom, paginación, marcador, pantalla completa) sin salir de la página. No usar para una imagen o vídeo sueltos (ver CAT-CON-013). |
| CAT-CON-016 | Contenedor de pestañas heterogéneo | Organizar bajo pestañas contenido de naturaleza distinta en cada una (texto, grid de cards, mapa, incluso otro contenedor de pestañas). No usar cuando todas las pestañas comparten la misma forma de contenido — para eso, CAT-CON-007 Tabs de contenido. |
| CAT-CON-017 | Lista de datos clave | Presentar un conjunto breve de pares etiqueta→valor como ficha técnica o resumen de datos (especificaciones, detalle de propiedad/ficha, condiciones). No usar para cifras grandes de impacto — para eso, CAT-CON-005 Stats. |
